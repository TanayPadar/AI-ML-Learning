# AI/ML Learning

I am learning AI and machine learning so I can apply it to robotics.

This repo is my practice space for the building blocks that matter on a robot: working with sensor and experiment data, writing vectorized Python, visualizing patterns, and turning numbers into decisions a model can use.

## Current focus

- **NumPy** — fast numerical work for signals, poses, and arrays
- **Pandas** — load, clean, filter, group, reshape, merge, and plot tabular data
- **Data collection** — APIs and HTML scraping with `requests` and Beautiful Soup
- **Visualization** — Matplotlib charts (bar, scatter, pie, histogram, box, stack, subplots)
- **Math** — probability, linear algebra (vectors, matrices)
- **Supervised ML** — regression and classification basics (scikit-learn)

## What's here

Practice scripts are grouped by topic:

| Folder | Contents |
|--------|----------|
| `01_Numpy/` | Vectorization basics |
| `02_Pandas/` | DataFrames through merging; sample CSV/JSON in folder |
| `03_Data_Collection/` | REST APIs and web scraping |
| `04_Data_Visualization/` | Matplotlib notes and saved example plots |
| `05_Maths_Probability/` | Sample space, events, union/intersection, rules |
| `07_Maths_Calcalus/` | Calculus notes (in progress) |
| `08_Maths_Linear_Algebra/` | Distance, lines, vectors, matrix intro |
| `09_Supervised_ML/` | Supervised learning intro and linear regression |

Most files are short `.py` scripts with comments; run them with the same Python environment where `pandas`, `matplotlib`, `requests`, `beautifulsoup4`, and `scikit-learn` are installed.
